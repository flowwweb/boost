# Boost screen map

Boost keeps the account tabs visible across every screen. The selected account is the only active account, and all schedules, formulas, and receipts follow that selection.

| Screen | Purpose | Primary actions |
| --- | --- | --- |
| Overview | Fast status for the selected account | Toggle Boost mode, switch platform account tabs, review followers/engagement, jump to Cycles or Schedule |
| Schedule | See recurring actions across the week | Review the colored bar calendar, queue, add a loop, and save the schedule |
| Cycles | Maintain repeatable actions | Edit names, action target (post, reply to others, reply to your posts, or DM), instructions, times, and per-account assignment |
| Accounts | Connect and check platform accounts | Choose Official API or Browser automation per account, refresh X status, connect or reauthorize an X account, add an account for X, LinkedIn, Instagram, YouTube, or Threads |
| Activity | Review local runs and receipts | Export receipts or pause Boost across accounts |
| Settings | Tune the selected project | Edit project name, posts/replies targets, schedule, token limit, spend alerts, theme, timezone, Codex task sync, the single Boost mode switch, and safety behavior |

The account connection choice is stored per project. Official API uses `xurl`; Browser automation is an explicit signed-in-session selection and does not store browser credentials. Live X writes stay in `draft` approval mode until the configured X app has OAuth credentials and the user changes that approval setting explicitly.
